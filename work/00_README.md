# TADSR official 4.0003 source bundles

All archives are below 1 GB.

| Archive | Contents |
|---|---|
| `01_FreqOrtho_SR_source_and_weight.zip` | FreqOrtho-SR source and `freqortho_sr.pkl` |
| `02_TADSR_source_and_LoRA_weights.zip` | TADSR source, `tadsr_tilefix.py`, and available LoRA checkpoints |
| `03_inference_pipeline_scripts_and_config.zip` | Prep, inference, comparison, selection, build scripts, prompts and scene config |
| `04_environment_dependencies_and_manifests.zip` | Requirements, Conda environment, and auxiliary model download notes |
| `05_official_4.0003_package.zip` | Official 4.0003 submission package |

The large TADSR base model and SD2.1-base are not inside these archives. Their download instructions are included in archive 04.
