建议先做“数据诊断 + 基线复现”，同时定向查论文，不要一开始就盲目找大量训练数据。这个比赛只有 5 组 GT，首先要弄清楚退化类型和评分偏好，否则训练方向容易跑偏。

推荐按以下顺序展开。

## 第一阶段：分析比赛数据

先重点检查 5 组验证集：

- LQ 与 GT 是否严格像素对齐
- 退化属于模糊、噪声、JPEG 压缩、过曝、暗光还是混合退化
- GT 相比 LQ 改变了哪些内容：锐度、颜色、曝光、纹理
- 五组分别对应什么场景
- 测试集与验证集的退化分布是否相近
- 是否存在多种相机处理风格

需要计算：

- PSNR、SSIM
- LPIPS
- DISTS
- NIQE、MUSIQ 等无参考指标
- 边缘清晰度、色差、频域差异

还应生成 LQ/GT 并排图、差分图和局部放大图。这个阶段的目标是形成一份“退化分析报告”。

## 第二阶段：建立保守基线

先不要训练，直接跑公开预训练模型，了解任务难度：

- Real-ESRGAN：非 Diffusion，仅用于对照
- StableSR
- DiffBIR
- SeeSR
- ResShift / SinSR
- SUPIR
- PASD

虽然最终方案必须是 Diffusion，但非扩散方法可以作为保真基准。

每个模型先处理 5 张验证图，然后统一缩回原始 4K 尺寸并计算指标。重点观察：

- 文字有没有被改写
- 人脸身份有没有变化
- 钟表刻度是否生成错误
- 植物叶片是否出现重复纹理
- 鸟类羽毛是否产生虚假细节

这个比赛的关键不是“生成得越锐越好”，而是“生成强度可控”。通常较低扩散强度、较低 CFG、更多原图结构约束会更稳。

## 第三阶段：定向阅读论文

论文不需要海量阅读，先围绕四条线：

1. 真实图像恢复  
   StableSR、DiffBIR、SUPIR、SeeSR。

2. 快速扩散恢复  
   ResShift、SinSR，解决 100 张 4K 图的推理成本。

3. 结构与内容保持  
   ControlNet、T2I-Adapter、reference conditioning、低频/高频分离。

4. 局部可控增强  
   人脸、文字和显著区域检测，采用分区强度或 mask conditioning。

读论文时主要记录：

- 输入条件如何注入
- 如何控制 hallucination
- 训练数据的退化合成方式
- 损失函数
- 推理步数与显存
- 是否支持 tiled inference

不要只记录模型排名。

## 第四阶段：再决定训练数据

完成前两个阶段后，才能判断需要什么数据。比较可能需要：

- 高质量自然图像：DIV2K、Flickr2K、LSDIR
- 真实图像恢复：RealSR、DRealSR
- 人脸：FFHQ 或合规的人脸恢复数据
- 文字场景：TextZoom、Real-CE
- 鸟类与植被：从允许使用的公开数据集中筛选高分辨率图像

训练时应从高清图片合成 LQ，而不是简单双三次下采样。退化链建议包含：

```text
模糊
→ 缩放
→ 噪声
→ JPEG压缩
→ 轻微曝光/色彩变化
→ 再次缩放或压缩
```

但退化参数必须根据验证集反推。还要保留所有第三方数据、模型和代码的来源，因为比赛要求决赛时申明。

## 推荐的技术路线

较稳妥的总体结构是：

```text
输入4K图像
→ 场景与退化检测
→ 保真预处理
→ 分块Diffusion恢复
→ 人脸/文字等区域使用较低生成强度
→ 重叠区域融合
→ 颜色与亮度回归原图
→ 保持原尺寸输出
```

最重要的工程难点是：

- 4K 分块推理及无缝融合
- 自动选择生成强度
- 防止文字和人脸被重绘
- 输出 JPEG 的编码参数
- 在未知评分权重下平衡 PSNR 与感知质量

## 近期最合理的工作安排

第一周可以这样做：

1. 完成 5 组验证集退化分析。
2. 建立统一评价脚本。
3. 选择 2～3 个公开模型跑基线。
4. 制作局部区域对比图。
5. 根据结果确定主模型。
6. 最后才开始组织训练数据和微调。

因此，眼下最优先的不是单纯“查论文”或“找数据”，而是先分析现有数据。完成数据诊断后，再有针对性地查论文和选择数据。下一步最适合直接建立项目代码框架，并生成第一份验证集分析报告。
